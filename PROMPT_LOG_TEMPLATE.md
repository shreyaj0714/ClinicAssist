## 1. Project overview
- **Project:** ClinicAssist – AI-powered clinic enquiry assistant
- **Domain:** Healthcare administration / technology
- **Problem:** Clinic staff may spend time answering repeated administrative questions.
- **Solution:** A demo chatbot that answers questions from fictional clinic information and records demo appointment requests locally.

## 2. AI tools used
- ChatGPT: project planning, code explanations, prompt refinement and debugging.
- Google Gemini API: generates chatbot responses in the application.
- Python + Streamlit: application and interface.
